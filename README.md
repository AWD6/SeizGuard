# SeizGuard

เว็บแอปติดตามการรับประทานยากันชัก บันทึกอาการชัก และอาการไม่พึงประสงค์

## การเข้าสู่ระบบและข้อมูลส่วนบุคคล

- ไม่ขอ HN หรือชื่อ–นามสกุลผู้ป่วย ใช้ชื่อผู้ใช้ที่ไม่ใช่ชื่อจริงและ PIN ตัวเลข 6 หลัก
- PIN จัดเก็บเป็นค่าแฮช PBKDF2 พร้อม salt ในเบราว์เซอร์
- ข้อมูลแอปเก็บใน `localStorage` ของอุปกรณ์ที่เปิดใช้งาน การเข้าสู่ระบบนี้ไม่ได้ซิงก์บัญชีข้ามอุปกรณ์
- เมื่อเปิดแอป โค้ดจะล้างค่า HN และชื่อผู้ป่วยที่ค้างจากรุ่นก่อนใน `localStorage`
- หน้าโปรไฟล์แสดง SeizGuard ID แบบสุ่ม พร้อมปุ่มคัดลอก ให้พยาบาลตรวจตัวตนและจับคู่ ID กับ HN/ชื่อในทะเบียน Google Sheet ส่วนตัวที่แยกจากชีตบันทึกอาการ
- เปิดการส่งไปยัง Google Form ใหม่แล้ว โดยกดปุ่มส่งบันทึกในหน้าโปรไฟล์ ส่งบันทึกยา อาการชัก และผลข้างเคียงแยกเป็นแถว ไม่ส่ง username, PIN, HN, ชื่อ, เบอร์โทร หรือข้อความอิสระจากแอป
- รายการยาที่กำลังรอ/ยังไม่ถึงเวลาจะไม่ถูกส่งเป็นผลว่าขาดยา
- เว็บไม่สามารถอ่านผลตอบรับของ Google Forms ผ่านคำขอข้ามโดเมน จึงรายงานว่าได้ส่งคำขอและให้ตรวจในชีต การส่งข้อมูลเดิมซ้ำอาจสร้างแถวซ้ำ
- ทะเบียนจับคู่ใช้สิทธิ์บัญชี Google ของผู้ดูแล ไม่ใส่ทะเบียนหรือ HN/ชื่อไว้ใน repository หรือเว็บสาธารณะ
- หากล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง บัญชีและรหัสอาจสูญหาย ต้องตรวจตัวตนและจับคู่รหัสใหม่กับพยาบาล ระบบยังไม่รองรับการกู้บัญชีหรือซิงก์ข้อมูลกลับจากชีต

เปิดผ่าน HTTPS หรือ localhost เพื่อใช้ Web Crypto สำหรับ PIN
