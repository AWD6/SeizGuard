# SeizGuard

บันทึกการกินยา อาการชัก อาการข้างเคียง และแจ้งเตือนยากันชัก/ยาโรคประจำตัวอื่น ตามแผนการรักษา

## เริ่มใช้กับผู้ป่วย

1. ลงทะเบียนด้วยชื่อผู้ใช้ที่ไม่ใช่ชื่อจริงและ PIN 6 หลัก หน้าโปรไฟล์แสดง SeizGuard ID สุ่ม
2. พยาบาลตรวจตัวตนต่อหน้า แล้วจับคู่ ID, HN และชื่อในทะเบียน Google Sheet ส่วนตัว ไม่ใส่ HN/ชื่อในเว็บผู้ป่วยหรือฟอร์มบันทึกอาการ
3. กด “เชื่อมข้อมูลอีกครั้ง” ในหน้าโปรไฟล์ ส่วนกลางยอมลงทะเบียนโทเคนอุปกรณ์หลังพบการจับคู่ในทะเบียนแล้ว
4. ยา/ชัก/ผลข้างเคียงซิงก์อัตโนมัติเมื่อออนไลน์ แผนยาจากผู้ดูแลอัปเดตเมื่อเปิดแอปและทุก 60 วินาที
5. เลือกเวลาเตือน (ค่าเริ่มต้น 30 นาที) แล้วกดเปิดแจ้งเตือนและอนุญาตที่เบราว์เซอร์ บน iPhone/iPad ต้องเพิ่มเว็บไปหน้าจอโฮมและเปิดจากไอคอนนั้น

บัญชี PIN และโทเคนยังเก็บในเบราว์เซอร์ การล้างข้อมูลหรือเปลี่ยนเครื่องต้องให้พยาบาลจับคู่ใหม่ ยังไม่มีหน้ากู้บัญชีข้ามอุปกรณ์

## ผู้ดูแล

- เปิด `admin.html` ใช้รหัส admin กับ SeizGuard ID เซิร์ฟเวอร์ตรวจรหัสที่แฮชและสถานะอนุมัติทุกคำขอ เซสชันหมดอายุใน 30 นาที
- แสดงชื่อ/HN แผนยา เวลา เป้าหมาย บันทึกชัก/อาการข้างเคียง ประวัติแพ้ยาที่ยืนยัน และนัดหมาย เพิ่ม/ยุติแผนยาได้ตามคำสั่งการรักษา
- เปอร์เซ็นต์ 7 วันคิดจากมื้อที่ถึงเวลาแล้วตามแผนที่ส่วนกลางรู้ ตั้งแต่วันที่แผนเข้าระบบ รวมมื้อที่ยังไม่มีผลบันทึกในตัวหาร ไม่รวมมื้อในอนาคต ไม่ใช่การรับรองว่ารับประทานยาจริง
- เจ้าของสร้างรหัสผู้ดูแลใหม่ได้ รหัสใหม่ยังใช้ไม่ได้จนอนุมัติ เพิกถอนแล้วเซสชันเดิมเรียกข้อมูลต่อไม่ได้
- `admin.html?demo=1` ใช้ข้อมูลสมมติ ไม่เรียกข้อมูลผู้ป่วยจริง
- ไม่มีรหัส admin, ชื่อ/HN หรือ private key ใน repository ไฟล์ `.local/` ถูกยกเว้นจาก Git

## ส่วนกลางและ Push

Google Apps Script ใช้ตาราง `SG_*` ในทะเบียนส่วนตัว เก็บแผนยา บันทึก โทเคนที่แฮช การอนุมัติ Push และประวัติการเข้าถึง API ผู้ป่วยไม่ส่งคืนข้อมูลระบุตัวบุคคล

ตัวตั้งเวลาฝั่งเซิร์ฟเวอร์ตรวจทุกนาทีและส่ง Web Push แบบไม่มีข้อมูลสุขภาพใน payload ด้วย VAPID ES256 Service Worker แสดงข้อความทั่วไปโดยไม่ต้องเปิดเว็บค้างไว้ การปิดแจ้งเตือน/DND การไม่มีเน็ต หรือข้อจำกัดระบบปฏิบัติการอาจทำให้ไม่ปรากฏหรือมาช้า จึงไม่ใช่นาฬิกาปลุกที่รับประกันเวลา

การออกจากบัญชีจะยกเลิก Push ของอุปกรณ์นั้น ปุ่มทดสอบส่งผ่านบริการ Push เมื่อมี subscription แล้ว หากยังไม่มีจะทดสอบเฉพาะการแสดงแจ้งเตือนในเครื่อง

ใช้ HTTPS หรือ localhost ข้อมูลที่ยังไม่ซิงก์อยู่เฉพาะเครื่องจนกลับมาออนไลน์ Google Form เดิมยังเป็นปลายทางแยก แต่ปุ่มส่งเดิมไม่แสดงเมื่อเชื่อมส่วนกลางนี้

## พัฒนาและติดตั้ง

ติดตั้ง dependencies ด้วย pnpm รัน `node backend/build.cjs` เพื่อสร้าง `backend/Code.gs` (ไม่ commit) และ `node --test tests/backend.test.cjs` เพื่อตรวจสิทธิ์ การเพิกถอน การแยกข้อมูล สถิติมื้อยา การเตือนข้ามวัน และลายเซ็น VAPID

ติดตั้งใหม่ด้วย `node backend/prepare-install.cjs <private-registry-id>` จะสร้างค่าลับใน `.local/` ใส่ Code.gs และ Install.gs ใน Apps Script ของเจ้าของ รัน installSeizGuard ครั้งเดียว อนุญาตสิทธิ์ แล้วลบฟังก์ชันติดตั้งที่มีค่าลับออก เผยแพร่ Web App และตั้ง endpoint ใน `cloud-config.js` ทุกคำขอยังต้องผ่านรหัส admin หรือโทเคนผู้ป่วย เก็บรหัสเจ้าของนอก repository

อัปเดตด้วย deployment ID เดิมและ New version ไม่รัน installer ซ้ำ ตัวตั้งเวลามีหนึ่งรายการ `sendMedicationReminders` ทุกหนึ่งนาที ติดตามโควตาและ execution errors เมื่อจำนวนผู้ใช้เพิ่มขึ้น
